                    Console

                    bash on the Pi, as the pidash user

                    Not connected

                    Shift+Tab leaves the terminal. Ctrl+Shift+C and Ctrl+Shift+V copy and paste. An idle session closes by itself. The audit log notes when a session starts and ends, never what you type.

                    System

                    • Update

                      Installs every pending Debian and Raspberry Pi OS update. Config files you changed are kept, and nothing is removed.

                    • Reboot

                      Restarts the Pi cleanly. It’s back in about a minute.

                    The last update needs a reboot to finish: a new kernel or firmware only runs after one.
